# 필수 명령어

## `/init`

**claude.md 문서 생성**

새 프로젝트를 만들고 클로드 코드를 시작할때 가장 먼저 실행해야 하는 명령어

프로젝트 구조 분석, claude.md  생성, 기술스택 파악, 컨벤션 추론 등을 함

## `/help`

**도움말 확인**

모든 명령어가 기억나지 않을 때 입력하는 도움말 확인 명령어다.

## `/clear`

**대화 초기화**

대화 내용을 모두 지우고 새로 시작한다.

## `/compact`

**컨텍스트 압축**

대화가 길어지면 커텍스트 윈도우가 가득 차서 이전 내용을 잊어버리게 된다. 컨텍스트가 길어질수록 클로드가 느려지거나 오동작 하는 상황이 벌어지게 되는데, 이때 쓰면 유용하다.
최근에는 CLI에서 자동 실행해주므로 현재 맥락과는 다른 별도의 작업을 수행할 때 /compact를 통해 한번 압축한 뒤 작업을 이어가면 좋다.

**예시**

```
/compact API 설계 관련 내용 중심으로 현재 컨텍스트를 요약해.
```

다음과 같은 경우에 사용한다.

- 긴 작업 중 "context window full" 경고가 나타날 때
- 대화가 길어져 응답 품질이 떨어질 때
- 특정 주제에 집중하고 싶을 때

## `/context`

**현재 세션의 윈도우 상태 시각화**

현재 세션의 토큰 사용량이나 대화 요소 별 상태들을 모니터링 할 수 있는 명령어다.

다음과 같은 경우에 사용한다.

- 현재 사용중인 모델의 버전
- 현재 소비한 토큰 / 전체 가용 토큰
- 자동 압축 트리거까지 얼마나 남았는지
- MCP에서 호출되는 토큰 소비량
